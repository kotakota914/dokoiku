## 契約の変更点（実装済み）

- `LIMITS.planSpotsMax = 8`、`LIMITS.plansPerMinute = 3`、`LIMITS.chatPerMinute = 5`、`LIMITS.chatMaxTurns = 10`
- `TRAVEL_MODES = ["transit","walking","driving"]`（初期値 `transit`）、`GOOGLE_TRAVEL_MODE`、`FALLBACK_SPEED_KMH.transit = 15`、`FALLBACK_TRANSIT_WAIT_MIN = 10`、`TRAVEL_CACHE_DAYS`
- `PLAN_METHODS`、`PRIORITIES` と `PRIORITY_WEIGHTS`（11.3）、`CANDIDATE_KINDS` / `CANDIDATE_LABELS`、`PLAN_CANDIDATES_MAX = 3`
- `FEATURES` に `route_planning_transit`、`ai_chat`。`USAGE_LIMITS` に `google_routes_transit`（月・組み合わせ件数）、`gemini`（日）
- `POPULARITY_RANKING`（上位 10% / 30%、投稿 2 件以上、10 スポット未満は都道府県）。旧 `POPULARITY_THRESHOLDS` は順位未計算時の代替
- `DEFAULT_VIEW`、`USE_DEFAULT_VIEW_WHEN_DENIED`、`TILE_ZOOMS = [8,11,14]`、`TILE_MAX_SPOTS = 500`、`TILE_CACHE_MAX_AGE_SEC = 60`、`MAP_MODE_FADE_SEC = 0.3`
- 型：`SpotSource` に `seed`、`Wishlist.baseLabel/baseLocation`、`PlanPreferences`、`PlanParams.{method,preferences}`（`pace/interests` は `preferences` へ移動）、`PlanLeg` と `PlanItem.next`、`SkipReason` に `excluded`、`PlanStats`、`PlanCandidate`、`PlanComputeResponse`、`PlanResult extends PlanCandidate`、`PlanSummary.method`、`PlanNavSegment` / `PlanWithNav`、`PlanChatMessage` / `PlanChatResponse`、`SystemStatus.capabilities.{transit,ai}`、`TravelTimeEntry.timeBucket`
- スキーマ：`updateListSchema`（name / base）、`listItemsSortSchema`、`planPreferencesSchema`、`planComputeSchema`（method / preferences / mode 既定 transit）、`planChatSchema`、`planLegSchema`、`planStatsSchema`、`planResultSchema`、`tilePathSchema` / `tileQuerySchema`
- Repository：`WishlistsRepo.setBase`、`SpotsRepo.recomputePopularity(scope?)`、`TravelCacheRepo.getMany(pairs, mode, timeBucket?)`、`purgeExpired(olderThanDays?)`

## 画面と導線（6・7 章）

- S-07 リスト詳細：拠点の設定（`house`）、各スポットに距離（`ruler`）、並べ替え（`arrow-up-down`：追加順 / 距離順 / 人気順 / カテゴリ別）、比較（`columns-3`、2〜3 件選択）、合計滞在時間の目安、保存済みプラン、「経路を作成」
- S-08 `/lists/[listId]/compare?spots=a,b,c`：横並び比較
- S-09 `/lists/[listId]/plan`：対象スポット（最大 8、初期値は 8 以下なら全選択、9 以上は必ず行きたい優先）、共通条件（出発地の初期値は拠点）、作り方 3 択（`wand-sparkles` / `list-checks` / `message-circle`）
- S-10 `/lists/[listId]/plan/chat`：チャット、読み取った条件の一覧・修正、作成
- S-11 `/lists/[listId]/plan/result`：最大 3 案の比較表（回れる数・合計移動・歩く距離・終了時刻・時間帯に合う数・入らなかった場所）、選んだ案のタイムライン（区間の移動手段アイコン `footprints` / `car` / `train-front`、公共交通は「目安」）、地図の線、並び替え・滞在時間変更 → recompute、保存
- S-12 `/plans/[planId]`：タイムライン、地図、各区間の「ナビを開始」（`navigation`、Google マップ URL）、削除、SNS 共有（既存）

## 環境変数（追加）

- `GOOGLE_ROUTES_API_KEY`：公共交通の行列。未設定なら概算
- `GEMINI_API_KEY`、`GEMINI_MODEL`（既定 `gemini-2.5-flash`）：AIと相談。未設定なら停止中
- `EXTERNAL_API_MOCK=true`：外部 API を記録済みの結果に置き換える（F-8-8）
